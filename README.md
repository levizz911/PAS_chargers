# Прогнозирование спроса и распределение ограниченного резерва мощности зарядных станций

## О проекте

Проект посвящён исследованию методов прогнозирования потребления электроэнергии и распределения ограниченного резерва мощности между зарядными площадками электромобилей.

Основная задача — определить, как выбор метода прогнозирования влияет на качество последующего распределения мощности.

Исследование проводится на исторических данных о зарядных сессиях из набора **CHARGED**.

## Цель исследования

Сравнить методы прогнозирования спроса и алгоритмы распределения мощности по следующим показателям:

- Точность прогноза потребления электроэнергии.
- Максимальный относительный дефицит мощности.
- Суммарный недостаток энергии.
- Использование доступного резерва.
- Вычислительное время алгоритмов оптимизации.

## Используемые методы

**Методы прогнозирования:**

1. Прогноз по предыдущему часу.
2. Линейная регрессия.
3. Случайный лес (Random Forest).
4. Градиентный бустинг (XGBoost).

**Методы распределения мощности:**

1. Линейное программирование (LP).
2. Пошаговое выравнивание относительного дефицита.

## Условия эксперимента

- **Количество площадок:** 5.
- **Период данных:** июнь — сентябрь 2023 года.
- **Шаг прогнозирования:** 1 час.
- **Доступный резерв мощности:** 6 кВт.
- **Обучение и настройка моделей:** июнь — июль.
- **Проверка результатов:** август — сентябрь.

Рассматриваются два сценария работы обучаемых моделей:

- **Сценарий А:** модель обучается на исторических данных и далее не обновляется.
- **Сценарий Б:** модель ежедневно переобучается с учётом новых наблюдений.

Значения базовой мощности площадок и доступного резерва заданы в рамках вычислительного эксперимента.

## Основные результаты

| Метод | MAE, кВт·ч | Средний максимальный дефицит |
|---|---:|---:|

| Линейная регрессия, Б | 0,5890 | 25,61% |
| Случайный лес, Б | 0,5726 | 25,32% |
| XGBoost, Б | 0,5621 | 25,37% |
| Идеальное распределение | — | 11,13% |

*Результаты получены на тестовом периоде август — сентябрь 2023 года.*

### Основные наблюдения

- Прогноз по предыдущему часу обеспечивает наименьшую среднюю абсолютную ошибку (MAE).
- Случайный лес с ежедневным переобучением обеспечивает наименьший средний максимальный относительный дефицит.
- Более высокая точность прогноза не всегда приводит к более эффективному распределению мощности.
- Ежедневное переобучение улучшает результаты некоторых моделей.
- Линейное программирование и пошаговое выравнивание формируют практически одинаковые решения.
- Пошаговое выравнивание выполняется существенно быстрее линейного программирования.

Наблюдаемые различия между методами по среднему дефициту невелики. Статистически устойчивое преимущество обучаемых моделей над прогнозом по предыдущему часу пока не установлено.

## Ограничения

Работа представляет собой вычислительное исследование, а не готовую систему управления зарядной инфраструктурой.

Дефицит мощности рассчитывается по историческому спросу в рамках принятой модели. Он не означает, что в реальной инфраструктуре были зафиксированы отказы в зарядке.

Полученные результаты относятся к выбранным пяти площадкам, периоду наблюдений и условиям эксперимента.
